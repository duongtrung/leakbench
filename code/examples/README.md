# Examples

Small, fast examples of the LeakBench trace schema and how to run the harness.

## Files

- `example_config.yaml` — a minimal, fast config (30 traces/class, 3 defenses).
- `synthetic_data/traces_sample.jsonl` — 12 example traces (one per class), in the
  canonical JSONL trace format documented in `../docs/data_format.md`. Generated by
  the calibrated generator with seed 20270214. **Synthetic smoke-test data, not a
  paper result.**
- `synthetic_data/generate_example_data.py` — regenerates the sample above (shows how
  to serialize a `TraceDataset` to JSONL).

## Run the example

```bash
python scripts/run_experiment.py --config examples/example_config.yaml --stage vantage
```

## Load the sample traces in Python

```python
import json
from leakbench.data.schemas import Trace

with open("examples/synthetic_data/traces_sample.jsonl") as fh:
    traces = [Trace.from_record(json.loads(line)) for line in fh]

print(len(traces), "traces; first has", traces[0].n, "calls, label", traces[0].label)
```

The records match the schema in `docs/data_format.md`, so they can also serve as a
tiny fixture for a real-data loader you write for `data.root`.
